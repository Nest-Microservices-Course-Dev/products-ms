# Product Microservice

## Development

1. Clonar el repositorio
2. Instalar las dependencias
3. Crear un archivo `.env` basado en el `.env.example` y configurar las variables de entorno
4. Ejecutar migración de prisma `npx prisma migrate dev` o `yarn prisma migrate dev`
5. Ejecutar el proyecto `npm run start:dev` o `yarn start:dev`
